# 赛事选手智能评分系统 · 产品说明文档

> 面向客户的产品介绍。本文档说明系统的**设计思路、评分规则、预测能力与选手画像**，帮助理解"分数是怎么来的、为什么这么设计、能给选手带来什么"。
> 文中所列数值均为**可后台配置的调优参数**（默认值），非写死逻辑。

---

## 一、产品概述

本系统是一套基于 **Elo 算法** 的赛事选手水平评分与画像体系，覆盖从"比分记录 → 积分计算 → 段位评定 → 胜负预测 → 能力画像"的完整链路。

**它解决的核心问题：**

1. **如何公平地衡量选手水平？** —— 让不同水平的选手在合理、可控的范围内加减分，避免"赢一场暴涨、输一场崩盘"。
2. **如何区分"本该赢/本该输"的比赛价值？** —— 同样是赢，碾压弱手和爆冷击败强手，含金量完全不同。
3. **如何给选手可理解的反馈？** —— 每一笔加减分都能拆解成因，选手能看懂"我为什么加了 8 分、扣了 3 分"。
4. **如何持续进化？** —— 参数可训练、规则可扩展，系统随赛事数据的积累越调越准。

---

## 二、设计核心思想：原子化 + 因子角色

系统的加减分**不是**把每一种比赛情景硬编码成一大串"如果…那么…"的判断（那样情景组合会爆炸式增长、难以维护），而是采用一套统一模板：

- 把影响加减分的所有因素，拆成**不可再分的"情景原子"**（共 11 个）；
- 把每个原子归入**有限的"因子角色"**（共 4 种）；
- 按统一公式模板组装，**由数据驱动**，不由代码逐条枚举。

**这样做的好处：**

- **可解释** —— 每一笔分数的变化都能追溯到具体是哪个因素起了作用。
- **可扩展** —— 以后要加新规则（如"连败保护""决赛权重加倍"），只需新增一个原子并插到对应角色位置，不动公式骨架。
- **可维护** —— 规则越多，反而越清晰，不会出现改一处崩一片。

## 三、评分规则：分数是怎么算出来的

### 3.1 影响加减分的 11 个情景原子

| 类别 | 情景原子 | 触发条件 | 对分数的作用 |
|---|---|---|---|
| **选手** | 定级期 | 累计场次 < 2 | 使用更高的成长速度，快速定位真实水平 |
| | 观察期 | 2 ≤ 场次 < 30 | 使用中等成长速度 |
| | 稳定期 | 场次 ≥ 30 | 使用较低成长速度，分数趋于稳定 |
| | 越级加分 | 定级期选手获胜且对手分高出达到门槛 | 额外加分，奖励"爆冷" |
| | 被越级扣分 | 对手触发越级加分且本方落败 | 额外扣分（由被爆冷的强手承担） |
| **比赛** | 比赛类型 | 1 人 = 单打，2 人 = 双打 | 单打取个人分，双打取队伍平均分 |
| | 胜负结果 | 比分高低 | 决定加还是减（S 值） |
| | 分差幅度 | 比分差距大小 | 差距越大，单场加减分放大） |
| | 赛事权重 | 赛事重要程度 | 重要赛事加减分相应放大 |
| **队伍** | 队伍 Elo 差 | 双方实力差距 | 决定"预期胜率"，越意外加减越多 |
| | 队内人数 | 1 人或 2 人 | 影响平均分计算与扣分分摊 |

### 3.2 加减分的四个"因子角色"

所有原子在公式里只扮演四种角色：

| 角色 | 作用 | 通俗解释 |
|---|---|---|
| **基础变化量** | 算"常规该加/减多少" | 赢强手该多加，输弱手该多扣 |
| **放大倍率** | 在基础上按比例放大 | 比分悬殊、赛事重要 → 同方向幅度更大 |
| **封顶器** | 限制单场最大波动 | 防止异常分数把排名打乱 |
| **额外补丁** | 在封顶之外独立加减 | 越级奖励/惩罚这类特殊机制 |

### 3.3 加减分公式（通俗版）

```
加减分 = 封顶(基础变化量 × 各放大倍率) + 额外加分 − 额外扣分
```

其中：

- **基础变化量的核心是 `实际胜负 − 预期胜率`：**
  - 赢球 → 实际=1，减去预期（越低于预期，即越"冷"，加得越多）；
  - 输球 → 实际=0，减去预期（结果自然为负，即扣分）；
  - **输球的扣分逻辑不需要单独写**，公式结构自动实现：本该赢（预期高）却输了 → 扣得多；本就该输（预期低）却输了 → 扣得少。
- **预期胜率** 由双方 Elo 分差计算：分差越大，强方预期胜率越高。（此"预期胜率"仅作为本场加减分的计算基准；对外做胜负预测时，还会在此基础上叠加交手记录与关系网修正，见第五章。）
- **放大倍率** 由分差幅度、赛事权重等叠加相乘。
- **单场封顶** 保证任何一场比赛的分数变化都在设定上限内。
- **越级加分/被越级扣分** 在封顶之后独立计算，用于快速修正"新选手初始分偏低"的低估。

## 四、关键业务规则说明

### 4.1 新手定级机制（三段成长速度）

系统按选手**累计场次**分三个阶段，成长速度（K 值）逐段降低：

| 阶段 | 场次 | 成长速度 | 设计意图 |
|---|---|---|---|
| 定级期 | 0~1 场 | 高（默认 40） | 快速把新手拉到接近真实水平的区间 |
| 观察期 | 2~29 场 | 中（默认 28） | 在真实水平附近继续调整 |
| 稳定期 | 30 场及以上 | 低（默认 20） | 分数稳定，只作小幅微调 |

> 这些数值均为可调优参数，见"参数持续优化"一节。

### 4.2 越级奖励与保护

- **越级加分**：处于定级期的新手，若击败了积分高出自己达到门槛（默认 150 分）的强手，会在常规加分之外获得**额外奖励分**，反映这是一场"含金量极高"的胜利。
- **被越级扣分**：相反地，被爆冷的强手会承担一部分**额外扣分**（由对手的越级奖励按比例分摊）。

### 4.3 单场封顶

无论对手多强/多弱、比分多悬殊，**单场比赛的常规加减分都被限制在一个上限内**，避免个别极端场次造成排名剧烈波动。越级奖励不占这个封顶额度（它是独立机制）。

### 4.4 赛事权重

不同级别的赛事可配置不同权重，重要赛事（如总决赛）的加减分比友谊赛相应放大，让"在重要比赛中的表现"更有分量。

## 五、胜负预测

系统在积分之上，提供独立的**胜负预测**能力。预测**并非只看双方积分差**，而是综合三个层次的对战信号，最终收敛为一个 5%~95% 的胜率：

```
预测胜率 = 封顶( Elo 基础胜率 + 直接交手修正 + 间接关系修正, 5%, 95% )
```

| 层次 | 依据 | 作用 |
|---|---|---|
| **Elo 基础胜率** | 双方队伍 Elo 分差 → 理论预期胜率 | 打底：水平差距决定的基本盘 |
| **直接交手修正** | 两人**历史直接交手**的胜负记录 × 场次系数 | 纠偏：真实的"你对他"战绩比理论更可信 |
| **间接关系修正** | 通过其他选手构成的**关系图**（最多 5 层路径搜索） | 补全：从没交过手，也能借"共同对手"推断优劣 |

- **为何要叠加交手与关系修正**：Elo 分概括的是一个人的整体水平，但"选手之间的克制关系"（某类打法特别克某类人）仅靠总分看不出来。这两层修正正是把**真实对战关系**补进预测，让预测比纯积分更贴近实战。
- 三个层次共享同一套**选手关系图**，逐层加权、数据驱动。
- 预测只做"查询展示"，**不会反过来修改积分**，与评分引擎各司其职、互不干扰。

## 六、六维能力雷达图

针对**单打**选手，系统基于**每一分的记分数据**，生成六维能力画像，帮助选手直观了解自己的技术风格。

### 六个维度（0~100 分，越高越强）

| 维度 | 含义 |
|---|---|
| **进攻** | 本方持有发球权时的得分能力 |
| **防守** | 本方接对方发球时的得分能力 |
| **发球** | 本方发球回合的整体得分率 |
| **接发** | 本方接发回合的整体得分率 |
| **抗压** | 落后时的韧性：逆转能力、关键分把握、连失控制 |
| **场区** | 换边前后表现的稳定性（对场地的适应性） |

### 附加指标

- **平均连续得分** / **平均连续失分**：反映得分与失分的连贯性。

### 计分原则

- 分数经过**归一化处理**，让各维度子展示在 0~100 区间、50 分为中位，视觉区分度更高。
- 抗压维度综合考虑：**最大落后分差、最长连续失分、能否逆转、关键分胜率、落后阶段失误**等，跨局按"逆转局/顺风局"加权汇总。
- 场区维度衡量**换边前后（11 分换边规则）的比分走势落差**，落差越小说明场地适应性越好。
- 只统计**单打**，双打不参与雷达图。

## 七、参数持续优化（训练）机制

系统中的各类数值（成长速度、封顶上限、越级门槛等）都是**可训练的超参数**，而非拍脑袋写死。

**优化方式：**

1. 以历史比赛数据作为样本，按时间顺序**重放**整个评分过程；
2. 用「预测胜率是否贴近真实结果」作为评价标准（对数损失）；
3. 通过自动搜索，找到让**预测准确度最高**的一组参数；
4. 将最优参数回写配置，全量重跑一次即生效。

**关键原则：**

- **按时间切分**训练集与验证集（用"过去的比赛"预测"未来的比赛"），避免数据泄露。
- 同时监控**校准度、新手收敛速度**等指标，防止过拟合。

这让系统具备"越用越准"的自我进化能力。

---

## 八、可扩展性与未来演进

得益于"原子化 + 因子角色"的架构，未来新增规则非常轻量：

| 想加的新规则 | 归类 | 实现方式 |
|---|---|---|
| 连败保护 | 封顶器 | 调整封顶逻辑，不改公式结构 |
| 近期状态（近 5 场胜率） | 放大倍率 | 新增一个倍率因子相乘 |
| 年龄/资历系数 | 成长速度 | 与赛龄同类，加一个判定 |
| 长期不打衰减 | 额外补丁 | 独立于预期差的修正项 |
| 决赛权重加倍 | 放大倍率 | 与赛事权重同类 |

同时，雷达图的维度和预测模型也可按业务需求持续扩充。

---

## 九、总结

本系统不是一套"写死的规则表"，而是一套**结构化、可解释、可训练、可扩展**的评分体系：

- **科学**：基于成熟的 Elo 算法，理论上分数能稳定反映选手真实水平。
- **公平**：屏蔽"本该赢/本该输"的失真，给"含金量"正确的奖励。
- **透明**：每一笔加减分都可拆解，选手看得懂、信得过。
- **进化**：参数可训练，规则可扩展，随赛事数据积累越调越准。
- **增值**：在积分之上叠加胜负预测与六维能力画像，为选手和赛事方提供超出"排名"的决策价值。
